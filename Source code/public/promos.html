    How it works

    Parse (code)

    Every timestamped camera, action, sound and dialogue line becomes a numbered "beat". Fully deterministic.

    Rules (code)

    Keyword and tone signals score each beat for hook and cliffhanger strength, then propose 20–60s windows. Free, instant, and works with no key.

    Judge (AI)

    The model reads each episode and picks promos by beat number, never raw timestamps. Code converts beats to times and snaps cuts so no line is cut mid-word.

    Montage (AI)

    A second pass joins the strongest moments from different episodes into stitched promos.

    Validate (code)

    Hard checks: length, something lands in the first 3s, clean in/out, inside episode bounds. Soft checks are keyword signals shown as warnings.

    Blind critic (AI) + human

    A second prompt sees only the clip, like a stranger scrolling past. Where it disagrees with the judge, the clip is flagged for the editor, who approves or rejects.
