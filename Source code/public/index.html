Three working prototypes

One for each problem in the brief. All three share one engine: deterministic code where correctness matters, an LLM where judgement matters, and code that checks the LLM's output. The model is swappable (Gemini, Claude, GPT, Groq, OpenRouter, a local Ollama, or any OpenAI-compatible gateway) by changing one setting.

Problem 1

Promo Finder

Reads a show's timestamped screenplays and returns ranked 20–60s promo clips: segment timestamps, the hook, the cliffhanger, and one line on why each works.

  • Timestamps can't be hallucinated: the model picks beat numbers, and code converts them to times
  • Cross-episode montages, plus a blind "cold viewer" critic
  • Editor approves, then exports CSV or an EDL for Premiere/Resolve
Open → Problem 2

Haq: AI Lawyer

Legal first aid for everyday money problems in India (deposit, refund, salary, cheque bounce, UPI, notices), by text or voice, in your language.

  • Builds the case file, explains your options, drafts the notice, rehearses with you
  • Cites only a hand-checked knowledge base; a code guard strips invented sections and cases
  • Rules force "see a lawyer" for police, court, family and danger cases
Open → Problem 3

Continuity Guard

A pre-render check for AI microdrama scripts. It catches name and speaker-label drift and contradictions before they become voice and face drift on screen.

  • Found 6 spellings of the Duke's estate in the 50 Kuku episodes
  • Every issue carries episode + timestamp evidence, verified against the script
  • Outputs a story bible the generation pipeline can use

Design principles used in all three

AI judges, code verifiesThe LLM never produces a fact the system can't check: timestamps come from beat numbers, laws from a knowledge base, and evidence quotes are matched against the script.
Works without AIPromo Finder and Continuity Guard have a free, instant rules-only mode, so they still produce useful output if the model or its quota fails.
Human in the loopEditors approve or reject. That acceptance rate is how quality is measured once a real team uses the tool.
Cheap at scaleA 50-episode show is about 65 lite-model calls (≈ $0.04 at paid Flash-Lite rates). The free tier was enough to make every raw output.

Run it yourself

Each tool runs in the browser. The default "demo key" uses a rate-limited free-tier Gemini key behind this site. For heavier use, pick a provider under Model and paste your own key; it stays in your browser. The same engine also runs as a CLI:

node cli/promos.mjs scripts.zip --strong-model gemini-3.8-flash   # Problem 1 → outputs/p1
node cli/lawyer.mjs tests/lawyer_cases.json                        # Problem 2 → outputs/p2
node cli/continuity.mjs scripts.zip                                # Problem 3 → outputs/p3
LLM_PROVIDER=anthropic ANTHROPIC_API_KEY=… node cli/promos.mjs …   # swap the model
